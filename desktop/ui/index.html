What this protects

Direct uploads need a short-lived Nostr signature from the owner or an unexpired friend. Open shelter accepts unknown keys only through signed mirrors and gives them no retention promise. Encrypt sensitive files before upload. Tor hides the node’s home address, not file size, timing or public Nostr identity.
